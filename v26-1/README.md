# WeDoIt v26.1.0 서비스 디자인 개편판

기존 v26.0-alpha.20의 데이터 구조와 기능을 그대로 유지하면서 첫 화면부터 설정까지 전체 화면을 서비스급으로 다시 구성한 후보입니다.

## 사용자가 처음 보는 변화

- 따뜻한 프리미엄 색·글자·간격 체계
- 오늘·목표·함께·통찰·나의 실제 화면 이동
- 첫 방문에서 `물 한 잔`, `깊은 숨 3번`, `안부 한 번`을 한 번 눌러 목표 생성과 첫 기록까지 완료
- 삶의 8영역을 점수가 아닌 `삶의 궤도`로 표시
- 개발·연결 상태 카드는 `나 > 고급 진단` 안으로 이동
- PC 왼쪽 메뉴와 폰 아래 메뉴가 같은 정보 순서를 사용
- PC의 휴대폰 이어보기 QR과 키보드 입력 유지

## 보존한 계약

- 데이터 구조 버전 6 유지
- 로그인 없이 기기에 저장
- 기존 목표·이벤트·회고·알림·함께 기능 승계
- 외부 출처 없는 첫 실행
- 첫 화면 압축 용량 27,086 / 110,000바이트
- 되돌림 대상: v26.0-alpha.20

## 아직 실제로 연결되지 않은 것

건강 플랫폼, Android 전용 기능, 원격 안전 전송은 기존과 같이 자동 실행하지 않습니다. 관련 개발 정보는 화면에서 숨기지 않고 `나 > 고급 진단`에서 필요할 때만 확인할 수 있습니다.
